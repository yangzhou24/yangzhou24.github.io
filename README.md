# Yang Zhou Academic Homepage

Static source for Yang Zhou's personal academic website. Adapted from Jon Barron's academic website.

## Main Files

- `index.html`: homepage content and section structure
- `stylesheet.css`: page styling
- `images/me.png`: profile photo path
- `images/papers/`: paper thumbnails and optional videos

## Maintenance

- Update the `ABOUT`, `PUBLICATIONS`, `EXPERIENCE` blocks in `index.html`
- Add paper thumbnails as `images/papers/<paper-key>.jpg`
- Optional paper videos can be added as `images/papers/<paper-key>.mp4`
- Remove the `is-placeholder` class from a media block after the corresponding file exists
